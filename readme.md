# 0xDecode - Sitio Web

Este es el repositorio del sitio web de 0xDecode, construido con React + Vite + TailwindCSS.  

## Despliegue

Para ejecutar este proyecto 

1- Clonar el repositorio

2- Instalar las librerías necesarias
```bash
  npm install
```

3- Ejectutar en modo developer
```bash
  npm run dev
```



## Convenciones



- Estructura : Las **rutas** están **definidas en "pages/"**, y los **componentes** de cada página **se definen en "components/<página>"**.


- Lenguaje: Todo el código y nombres de archivos deben estar en inglés.
- Estilos: Exclusivamente con TailwindCSS salvo animaciones o excepciones.
- Componentes: Reutilizables, nombrados en PascalCase (Ej: MyComponent.jsx).
- Commits: Estilo simple tipo:
  - **feat**: add community section
  - **fix**: correct navbar spacing
  - **refactor**: split hero section into components
